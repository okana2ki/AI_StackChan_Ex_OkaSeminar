# 岡ゼミ版について（本家との違い）

このリポジトリは [Beko6648/AI_StackChan_Ex](https://github.com/Beko6648/AI_StackChan_Ex) を
**M5Stackchan（M5Stack CoreS3）+ Gemini Live** で動くように修正したものです。
ライセンスは元と同じ MIT です（`LICENSE` を参照）。

## なぜ本家をそのまま使わないのか

本家は M5Stack Core2 を主な対象としているため、**CoreS3 で使うと不具合が同時に発生します。**
授業時間内に自力で原因にたどり着くのは困難なため、修正済みのものを配布します。

| 修正した内容 | 本家のままだと起きること |
|---|---|
| M5Unified を 0.2.15、M5GFX を 0.2.22 に固定（GitHubのタグを直接指定） | **画面が極端に暗い・タッチが効かない・首が動かない**が同時に発生 |
| 書き込み速度を 1500000 → 460800 に変更 | 書き込み中に**本体が起動しなくなる**（実際に発生） |
| 音声再生のチャンネルを 0 に固定 | AIの声が**早口になり、絶えず途切れる** |
| 音声バッファを 2枚 → 3枚 に変更 | 同上（チャンネル固定と両方必要） |
| Gemini Live の接続方式を修正 | 接続直後に切断される／返事が返らない |
| 画面表示を日本語化、タッチ操作を改善 | 英語表示のまま。発話中に触ると**本体が固まる** |
| キャラクター設定の読み込みを有効化 | 性格設定ファイルが一切反映されない |

> 特に上の3つは、**症状から原因を推測することがほぼ不可能**です。
> 画面が暗いのとタッチが効かないのが「同じ1つの原因」だとは、まず気づけません。

## 授業で使う場合

- 詳しい手順は **「スタックチャン AI会話マニュアル」** を参照してください
- **第18章（ライブラリのバージョンを揃える）は不要です。** この版では対応済みです

## APIキーとWi-Fiパスワードについて

`Copy-to-SD/yaml/SC_SecConfig.yaml` には個人のAPIキーとWi-Fiパスワードを書きます。
このファイルは `.gitignore` で除外されており、**GitHubには上がりません。**

配布されているのは中身が伏せ字になった `SC_SecConfig.yaml.example` です。
これをコピーして `SC_SecConfig.yaml` にリネームし、各自の値を入れて使ってください。

> **⚠️ APIキーを書いたファイルを、そのままGitHubに上げないでください。**
> 上げてしまうとキーが第三者に使われ、無効化されます。

## 主な変更ファイル

| ファイル | 内容 |
|---|---|
| `firmware/platformio.ini` | ライブラリのバージョン固定、書き込み速度 |

| `firmware/src/llm/Gemini/GeminiLive.cpp` | Gemini Live との通信 |
| `firmware/src/mod/AiStackChan/RealtimeAiMod.cpp` | 画面表示・タッチ操作 |
| `firmware/src/main.cpp` | 起動処理、画面の明るさ、診断ログ |
| `Copy-to-SD/characters/` | 性格設定（okazemi / uranai を追加） |

## 技術的な記録

`doc/岡ゼミ_技術メモ.md` に、実際に発生した不具合とその原因・対処を、
**判明した経緯とあわせて**記録してあります。
「症状からは原因が推測できなかった」ケースが多いため、同じ問題に当たったときの
手がかりとして残しています。

> なお、リポジトリ直下の `CLAUDE.md` は本家の作者が書いたもので、
> 岡ゼミ版の記録は上記 `doc/岡ゼミ_技術メモ.md` の方です。

## AIコーディングエージェントで作業する場合

リポジトリ直下の **`AGENTS.md`** に、岡ゼミ版固有の制約をまとめてあります。
Codex などは、このファイルを自動で読み込みます。

- **触ってはいけない設定**（ライブラリのバージョン、書き込み速度、Gemini への送信形式、音声再生）
- **不具合調査の手順**（まず無料枠を確認する。症状からコードを推測しない）
- ビルド・書き込みコマンド、シリアルログの読み方

`firmware/AGENTS.md` は本家の作者によるコーディング規約です。両方が読まれます。
